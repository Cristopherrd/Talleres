### Parte 2: Análisis de datos (EDA)

Utilizando la lista de objetos obtenida en la parte anterior, implemente la lógica dentro del mismo programa para obtener los siguientes indicadores:

1. **Sumatoria:** Calcule el total de goles marcados por todos los jugadores en el listado.
2. **Promedio:** Obtenga el promedio de partidos jugados (`PJ`) de todos los jugadores.
3. **Valores Extremos:** Encuentre el valor **máximo** y el valor **mínimo** de la columna de partidos jugados (`PJ`).
4. **Estadístico Adicional (Desviación Media):** Calcule la Desviación Media de los goles. Este estadístico mide cuánto se alejan, en promedio, los goles de cada jugador respecto a la media aritmética. 

La fórmula es:

$$
DM = \frac{\sum_{i=1}^{n} |x_i - \overline{x}|}{n}
$$

Donde:
- $x_i$: es el número de **goles** de cada jugador.
- $\overline{x}$: es el promedio de **goles** del conjunto.
- $n$: es el número total de jugadores.
- $| \dots |$: representa el valor absoluto.

```scala
  package clase12

import cats.effect.{IO, IOApp}
import fs2.text
import fs2.io.file.{Files, Path}
import fs2.data.csv.*
import fs2.data.csv.generic.semiauto.*

import models.Jugador

given CsvRowDecoder[Jugador, String] = deriveCsvRowDecoder[Jugador]

object Estadisticas:

  def sumaTotal(valores: List[Int]): Int =
    valores.sum

  def promedio(valores: List[Int]): Double =
    if valores.isEmpty then 0.0
    else valores.sum.toDouble / valores.length

  def valorMaximo(valores: List[Int]): Int =
    if valores.isEmpty then 0
    else valores.max

  def valorMinimo(valores: List[Int]): Int =
    if valores.isEmpty then 0
    else valores.min

  def desviacionMedia(valores: List[Int]): Double =
    val prom = promedio(valores)
    valores.map(v => math.abs(v - prom)).sum / valores.length


object EDA_Jugador extends IOApp.Simple:

  val rutaArchivo = Path(
    "C:\\Users\\crist\\IdeaProjects\\ActividadSemana12\\src\\main\\resources\\data\\LigaPro2025-2026.csv"
  )

  val run: IO[Unit] =
    val leerCSV: IO[List[Jugador]] =
      Files[IO]
        .readAll(rutaArchivo)
        .through(text.utf8.decode)
        .through(decodeUsingHeaders[Jugador](','))
        .compile
        .toList

    leerCSV.flatMap { jugadores =>

      val goles = jugadores.map(_.Goles)
      val partidos = jugadores.map(_.PJ)

      val totalGoles = Estadisticas.sumaTotal(goles)
      val promedioPJ = Estadisticas.promedio(partidos)
      val maxPJ = Estadisticas.valorMaximo(partidos)
      val minPJ = Estadisticas.valorMinimo(partidos)
      val desvMediaGoles = Estadisticas.desviacionMedia(goles)

      IO.println("\n" + "-" * 50) >>
        IO.println(" ANALISIS EXPLORATORIO - LIGA PRO") >>
        IO.println("-" * 50) >>
        IO.println(s"Cantidad de jugadores: ${jugadores.length}") >>
        IO.println(s"Goles totales registrados: $totalGoles") >>
        IO.println(f"Promedio de partidos jugados: $promedioPJ%.2f") >>
        IO.println(s"Máximo de PJ: $maxPJ") >>
        IO.println(s"Mínimo de PJ: $minPJ") >>
        IO.println(f"Desviación media de goles: $desvMediaGoles%.2f") >>
        IO.println("-" * 50)

    }.handleErrorWith { e =>
      IO.println(s"No se pudo procesar el archivo CSV: ${e.getMessage}")
    }

```
